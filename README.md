# SOLARTOUCH Project Hub

ระบบบริหารงานติดตั้งโซลาร์บ้านของทีม ตั้งแต่รับงาน ออกแบบใบเสนอราคา ขออนุญาตท้องถิ่น แจ้ง กกพ. ไปจนถึงการไฟฟ้าเปลี่ยนมิเตอร์ ทุกคนในทีมใช้งานพร้อมกันได้ทั้งบนคอมพิวเตอร์และมือถือ และเห็นการอัปเดตทันที

- โฮสต์หน้าเว็บฟรีบน **GitHub Pages**
- เก็บข้อมูลและซิงก์เรียลไทม์ด้วย **Firebase Firestore** (แพ็กเกจฟรี Spark เพียงพอสำหรับทีมเล็ก)
- เข้าสู่ระบบด้วย **บัญชี Google** เฉพาะอีเมลที่ผู้ดูแลอนุญาตเท่านั้น
- ติดตั้งบนมือถือเป็นแอปได้ (เปิดเว็บ → เมนูเบราว์เซอร์ → "เพิ่มไปยังหน้าจอโฮม")

ถ้ายังไม่ได้ตั้งค่า Firebase เว็บจะเปิดใน **โหมดตัวอย่าง** ที่ไม่บันทึกข้อมูล ใช้ลองดูหน้าตาระบบได้

---

## ตั้งค่าครั้งแรก (ประมาณ 15 นาที)

### 1. สร้างโปรเจกต์ Firebase
1. เข้า https://console.firebase.google.com แล้วกด **Create a project** (ตั้งชื่อเช่น `solartouch-hub`) ปิด Google Analytics ได้
2. เมนู **Build → Firestore Database** → **Create database** → เลือกตำแหน่ง `asia-southeast1 (Singapore)` → เลือก **Start in production mode**
3. เมนู **Build → Authentication** → **Get started** → แท็บ **Sign-in method** → เปิด **Google** → ใส่อีเมลติดต่อ → Save
4. เมนู ⚙️ **Project settings** → หัวข้อ **Your apps** → กดไอคอน **`</>`** (Web) → ตั้งชื่อแอป → **Register app**
5. คัดลอกค่าใน `firebaseConfig` ที่แสดงขึ้นมา

### 2. ใส่ค่าในโปรเจกต์
1. เปิดไฟล์ `firebase-config.js` วางค่าที่คัดลอกมาแทนค่าว่างใน `firebaseConfig`
2. ใส่อีเมล Gmail ของผู้ดูแลระบบใน `ADMIN_EMAILS` เช่น `["owner@gmail.com"]`
3. เปิดไฟล์ `firestore.rules` แก้ `['your.name@gmail.com']` เป็นอีเมลผู้ดูแลเดียวกัน (ตัวพิมพ์เล็ก)

> ค่าใน `firebaseConfig` เป็นค่าสาธารณะของเว็บแอป เก็บใน GitHub ได้ตามปกติ ข้อมูลลูกค้าปลอดภัยเพราะกฎใน `firestore.rules` อนุญาตเฉพาะสมาชิกที่ล็อกอินแล้ว

### 3. ติดตั้งกฎความปลอดภัย
ใน Firebase Console → **Firestore Database → Rules** → ลบของเดิม วางเนื้อหาไฟล์ `firestore.rules` ทั้งหมด → **Publish**

### 4. อนุญาตโดเมน GitHub Pages
Firebase Console → **Authentication → Settings → Authorized domains** → **Add domain** → ใส่ `<ชื่อบัญชี GitHub>.github.io`

### 5. เปิด GitHub Pages
GitHub repo → **Settings → Pages** → Source: **Deploy from a branch** → Branch: `main` / `/ (root)` → Save
รอ 1–2 นาที เว็บจะอยู่ที่ `https://<ชื่อบัญชี>.github.io/<ชื่อ repo>/`

### 6. เพิ่มทีมงาน
ผู้ดูแลเข้าเว็บ → ล็อกอินด้วย Google → เมนู **ทีมงาน** → พิมพ์ Gmail ของสมาชิก → **เพิ่มสมาชิก**
จากนั้นส่งลิงก์เว็บให้สมาชิก ล็อกอินด้วย Gmail ที่เพิ่มไว้ก็ใช้งานได้ทันที

## โครงสร้างไฟล์

```
index.html            หน้าเว็บหลัก
build_artifact.py     สร้างไฟล์เวอร์ชัน Claude artifact จากโค้ดชุดเดียวกัน
vendor/               ไฟล์ประกอบของแผนที่ (Leaflet)
styles.css            ธีมสีน้ำเงิน-ส้ม (รองรับโหมดมืด)
app.js                การทำงานทั้งหมด
firebase-config.js    ค่าเชื่อมต่อ Firebase และอีเมลผู้ดูแล  ← แก้ไฟล์นี้
firestore.rules       กฎความปลอดภัยฐานข้อมูล             ← วางใน Firebase Console
manifest.webmanifest  ให้ติดตั้งเป็นแอปบนมือถือ
sw.js                 แคชหน้าเว็บให้เปิดเร็วและใช้ออฟไลน์
```

## หมายเหตุเรื่องพื้นที่เก็บรูป
รูปถูกย่อขนาด (ประมาณ 100–400 KB ต่อรูป) แล้วเก็บใน Firestore โดยตรง จึงใช้แพ็กเกจฟรีได้โดยไม่ต้องเปิด Firebase Storage
แพ็กเกจฟรีมีพื้นที่ 1 GB รองรับรูปได้หลายพันรูป ถ้าใกล้เต็มให้ลบรูปงานที่ส่งมอบแล้วหลังเก็บ PDF ไว้

## ปรับแต่ง
- **ราคาเริ่มต้นในใบเสนอราคา** แก้ในฟังก์ชัน `buildItems()` ใน `app.js`
- **รายการเอกสารขออนุญาต** แก้ในตัวแปร `DOCS` ใน `app.js`
- **หมวดรูปถ่าย** แก้ในตัวแปร `PHOTO_CATS` ใน `app.js`
- **ข้อมูลบริษัทและเงื่อนไขในใบเสนอราคา** แก้ในฟังก์ชัน `quoteDoc()` ใน `app.js`

รายการเอกสารเป็นชุดมาตรฐานของงานโซลาร์บ้าน ข้อกำหนดจริงอาจต่างกันตามการไฟฟ้าเขตและท้องถิ่น ตรวจสอบประกาศล่าสุดของ กฟภ./กฟน. และ กกพ. ก่อนยื่น
